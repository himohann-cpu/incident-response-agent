# Triage an incident with no clear cause

1. Check the four signals for the service: traffic, errors, latency, saturation.
2. Compare traffic now with the same hour last week.
3. Check each direct dependency's dashboard.
4. Widen the change window to 72 hours and include infrastructure changes.
5. If nothing stands out after 20 minutes, escalate to the service owner.
